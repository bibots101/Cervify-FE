## **Project**
- **Description**: This repository contains the React frontend for Cervify. It provides user authentication, image upload, prediction requests to a backend service, progress tracking, and a history panel.
- **Repository**: Frontend only — expects a separate backend API.

## **Tech Stack**
- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Bundler / Dev Server**: Vite
- **Utilities**: Fetch API for backend calls

## **Features**
- User signup & login
- Image upload and prediction submission
- Real-time pipeline progress polling
- User history retrieval and image deletion
- Account deletion

## **Configuration**
The frontend calls a backend API. By default the backend URL is set in `src/services/api.js` to `http://127.0.0.1:8000`.

If your backend runs at a different address, update the `BACKEND_URL` constant in [src/services/api.js](src/services/api.js#L1).

Note: You can change this to read from an environment variable if you prefer, for example using `import.meta.env.VITE_API_URL` and Vite's `.env` files.

## **Usage / Quick Walkthrough**
1. Start the frontend with `npm run dev`.
2. Ensure the backend API is running and reachable at the `BACKEND_URL` in `src/services/api.js`.
3. Sign up or log in via the UI.
4. Upload an image on the Model Interface page and submit a prediction.
5. Monitor pipeline progress and view results in the result panel.
